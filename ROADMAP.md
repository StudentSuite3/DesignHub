# Roadmap

DesignHub grows one studio at a time. Every studio follows the same principles: open source, local first, no login, no backend, offline first, keyboard first and production ready.

Have an idea, or want to help build something here? Open an issue or discussion — see [CONTRIBUTING.md](CONTRIBUTING.md).

---

## V1 — Foundations ✅ _(released 1.0.0)_

### Typography

- Google Fonts browser, search, categories, favorites and recents
- Variable font playground and OpenType controls
- Font pairing engine
- Fluid type scale, `clamp()` generator and responsive preview
- Exports: CSS, Tailwind, SCSS, React, JSON tokens

### Colors

- Palette generator with locks and harmony modes
- OKLCH editor with HEX / RGB / HSL / OKLCH
- Shade generator (50–950) and gradient builder (linear, radial, conic)
- WCAG contrast checker and color blindness preview
- Exports: CSS variables, Tailwind, JSON tokens, SVG gradient

### Icons

- Iconify search and collections
- SVG editing: stroke, corners, color, rotate, flip
- SVG, React, PNG and ICO exports
- Favicon generator

### Export

- Shared design-token system
- CSS variables, SCSS, Tailwind config, React theme, JSON tokens
- One-click copy, JSON download and live preview

---

## V2 — Surfaces & quality 🚧 _(planned)_

### Background Studio

- Mesh gradients, noise, grain and patterns
- Exports as CSS, SVG and PNG, sized for social and device wallpapers

### Effects Lab

- Shadows, glows, borders and blend modes, with elevation scales exported as tokens
- Motion presets (easing curves, durations) as tokens

### Accessibility

- APCA contrast alongside WCAG 2.x
- Focus-ring and target-size auditing for exported themes
- Full-page color blindness simulation of the live preview

### SVG Playground

- Paste or drop any SVG to optimize, restyle and inspect it
- Path simplification and `currentColor` normalization
- Sprite sheet and icon-font generation

---

## V3 — Brand 🔭 _(exploring)_

### Brand Studio

- Logo lockups, clear space and minimum size rules
- A complete brand guideline document built from your tokens

### Mockups

- Drop your palette, type and icons into device, print and packaging mockups

### Social Studio

- Open Graph images, social banners and post templates generated from your brand tokens

### Brand DNA

- One portable file that describes your whole identity (tokens, fonts, icons, rules)
- Import it into any DesignHub studio, or share it with your team

---

Items are ordered by priority but not by date. Scope may change based on community feedback.
